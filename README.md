# Александра Гуляева — AI-дизайнер для маркетплейсов

Готовое статическое портфолио. Без сборки, зависимостей, внешних шрифтов и платных сервисов.

## Посмотреть на компьютере

Распакуйте архив целиком и откройте index.html двойным щелчком. Папка assets должна оставаться рядом с ним.

## Опубликовать на GitHub Pages

1. Создайте новый публичный репозиторий, например ai-design-portfolio. Если у вас уже есть другое портфолио, новый репозиторий сохранит его без изменений.
2. Загрузите содержимое этого архива в корень репозитория: index.html, style.css, app.js, projects.js, favicon.svg и папку assets. Загрузить нужно распакованные файлы, а не ZIP. index.html должен лежать непосредственно в корне.
3. В настройках репозитория откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку / (root), затем Save.
5. После завершения публикации GitHub покажет ссылку на сайт. Обычно для такого репозитория это https://ВАШ-ЛОГИН.github.io/ai-design-portfolio/.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что внутри

- Четыре проекта, 21 изображение. Все карточки включены.
- Celimax: два варианта по три карточки.
- Luné: три варианта по три карточки.
- The Body Shop: четыре карточки.
- HomeTown: две карточки.
- Переключение вариантов, полноэкранное модальное окно, стрелки клавиатуры, Escape, свайпы на мобильном.
- Адаптивная верстка. На телефоне серии листаются горизонтально.
- Контакты в шапке и подвале.
- Изображения оптимизированы в WebP без обрезки. Исходные PNG остаются в вашем первоначальном архиве.

## Редактирование

Тексты и контакты — index.html. Цвета и оформление — style.css. Проекты, порядок карточек, описания и варианты — projects.js. Логика просмотра — app.js.

В projects.js поле images содержит номера файлов в assets: 2 соответствует assets/02.webp. Поле alts содержит подписи в том же порядке. Для добавления новых файлов придерживайтесь той же нумерации или адаптируйте функцию src в app.js.

Упоминания Skyeng и «Золотого Яблока» описывают предыдущий опыт автора. Представленные бренды не обозначены как прямые клиенты. Коммерческие результаты и рост продаж не заявляются.
